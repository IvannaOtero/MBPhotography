# MBPhotography Website

## Project Description

This project is a website for **MBPhotography**, a family-owned photography business based in the PNW.

The website is designed to help showcase photography work, provide information about the business, allow potential clients to get in touch, and make it easy for customers to schedule photography sessions online.

### Main Pages

- **Home** – Introduction to MBPhotography and featured photography.
- **Portfolio** – Gallery showcasing previous photography sessions.
- **About Us** – Information about the photographers and the story behind the business.
- **Contact** – Ways for clients to reach us through email, phone, and social media.
- **Schedule Your Appointment** – Online scheduling page where clients can select an available date and time for their photography session.

### Goal

Create a simple, modern, and user-friendly website that helps MBPhotography grow its online presence and connect with new clients.
